# Bradiant identity

The project identity uses the logo supplied by the project owner on 21 November 2026.

- `bradiant-logo.png`: byte-for-byte copy of the supplied original image (1,254 × 1,254 px).
- `bradiant-brand-lockup.png`: cropped presentation variant included in the downloadable full-source bundle; the canonical repository image is the unmodified source PNG.
- `bradiant-icon.png`: cropped mark for compact uses, retaining the supplied artwork.

All derivatives are crops of the supplied raster source. No regenerated artwork has been substituted. The logo is not part of the scientific manuscript body because the official JOSS paper style handles typesetting.
